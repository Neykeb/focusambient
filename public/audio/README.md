## Technische Entscheidung

Die Dateien besitzen 256 kbit/s und sind zusammen ungefähr 15,4 MB groß. Für
das lokale Schulprojekt bleiben die Originaldateien erhalten. Der Browser lädt
eine Datei erst, wenn ein Geräusch gestartet wird. Vor einer größeren
öffentlichen Veröffentlichung kann besonders die Wald-Datei mit einem
geeigneten Audio-Encoder vorsichtig komprimiert werden.
