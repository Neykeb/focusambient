# Eigene Audiodateien

Lege eigene, rechtmäßig verwendete Audiodateien in diesem Ordner ab. Empfohlen sind komprimierte MP3-, OGG- oder WebM-Dateien mit sauberem Loop-Anfang und -Ende.

Anschließend registrierst du jede Datei in `src/features/audio/model/externalSoundscapes.ts`. Der Browser lädt die Datei erst beim Starten des Sounds.

Audiodateien können groß sein. Prüfe vor einem Git-Commit Dateigröße, Lizenz, Lautstärke und Loop-Qualität.
